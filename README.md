# 🔥 Viral Thread Builder

Web app untuk membuat konten viral siap posting di Threads.

## 🚀 Deploy

1. Upload semua file ke GitHub repository
2. Buka https://vercel.com → Import repository
3. Klik Deploy
4. Done!

## 🛠 Tech Stack

- **Frontend**: Next.js + React + Tailwind CSS
- **Backend**: Python Serverless Function (Vercel)
- **Hosting**: Vercel
